## Pré-requisitos

- Node.js **24+** (exigido em `engines` do `package.json`)
- npm 10+

## 1. Clone e instale

```bash
git clone https://github.com/thiagofinch/arkom-dash.git
cd arkom-dash
npm install
```

## 2. Configure variáveis de ambiente (opcional)

<Note>
  A interface funciona **sem backend** — dados mock por padrão. Só configure o `.env.local` para login real, dados reais ou Genesis com LLM de verdade.
</Note>

```bash
cp .env.example .env.local
```

Em desenvolvimento, sobrescreva as URLs canônicas:

```bash
APP_URL=http://localhost:3000
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

Veja a lista completa em [Variáveis de Ambiente](/environment/setup).

## 3. Rode o servidor de desenvolvimento

```bash
npm run dev
```

O app sobe em `http://localhost:3000`.

## Scripts disponíveis

| Comando | O que faz |
|---------|-----------|
| `npm run dev` | Servidor de desenvolvimento |
| `npm run build` | Build de produção |
| `npm run start` | Serve o build de produção |
| `npm run lint` | ESLint 9 |
| `npm run typecheck` | `tsc --noEmit` (strict) |
| `npm run check` | lint + typecheck + build, em sequência |
| `npx playwright test` | Suítes E2E (Genesis e jornadas de solução) |

<Warning>
  Nunca commite o `.env.local`. Credenciais de migration (`ARKOM_MIGRATION_DATABASE_URL`) ficam **somente** na estação do operador — jamais no runtime da aplicação.
</Warning>
