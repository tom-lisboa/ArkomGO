Como alimentar a base do CRM

Três caminhos levam dados para dentro do CRM: planilha CSV, API pública e webhook de entrada. Este guia mostra o que cada um cobre, qual usar na carga do dia 1, o formato exato dos arquivos e como montar a chamada de API — com os campos reais de cada entidade.

As três vias, e quando usar cada uma

02

Importar por CSV

Não existe botão de baixar modelo — mas o próprio sistema gera o template. O arquivo que a tela exporta usa exatamente os cabeçalhos que a importação reconhece sozinha. Comece por aí e não há como errar nome de coluna.

  1. 1

    Gerar o template a partir do próprio CRM

    Abra Empresas e clique em exportar CSV. Faça o mesmo em Contatos. Mesmo com a base vazia, o arquivo sai com a linha de cabeçalho — e é ela que interessa.

    Apague as linhas de exemplo, mantenha o cabeçalho intacto e entregue os dois arquivos ao cliente como modelo de preenchimento.

  2. 2

    Preencher respeitando quatro regras

    O leitor de CSV é simples, e isso impõe limites que valem avisar antes de o cliente montar a planilha:

    • Nenhuma vírgula dentro dos valores. Mesmo entre aspas, “Acme, LTDA” é lido como duas colunas e desalinha o registro inteiro. Troque por “Acme LTDA” ou “Acme - LTDA”.
    • Salvar como CSV UTF-8, sem BOM. A marca invisível que o Excel escreve no início do arquivo gruda no primeiro cabeçalho e derruba o reconhecimento automático da primeira coluna.
    • Uma linha de cabeçalho, sempre. Arquivo sem cabeçalho, ou com título/logo acima da tabela, é recusado.
    • Não reimportar o mesmo arquivo. Não há deduplicação: importar duas vezes cria tudo em duplicidade. Não existe atualização por e-mail ou documento.
  3. 3

    Importar Empresas primeiro

    Sempre nessa ordem. As empresas precisam existir antes para que os contatos possam ser vinculados a elas depois.

    Na tela de Empresas, escolha importar CSV. O sistema abre em três etapas: enviar arquivo → conferir o mapeamento de colunas → revisar a prévia. O mapeamento vem preenchido automaticamente pelo nome do cabeçalho; qualquer coluna extra pode ser marcada como “Ignorar”.

  4. 4

    Importar Contatos

    Mesmo fluxo, na tela de Contatos.

    Atenção ao vínculo: a coluna Empresa existe no arquivo exportado, mas é ignorada na importação. O contato entra sem empresa associada. O vínculo precisa ser feito depois — na tela do contato, ou em lote pela API.

  5. 5

    Conferir antes de seguir

    Confira a contagem de registros e abra três ou quatro fichas ao acaso, olhando telefone, e-mail e acentuação. Acento quebrado indica arquivo salvo fora de UTF-8 — nesse caso, apague o que entrou e importe de novo com a codificação certa.

Cabeçalhos aceitos

Cole exatamente assim na primeira linha da planilha. Colunas marcadas com * são obrigatórias — linhas sem elas são descartadas em silêncio.

03

API pública

É o caminho para tudo que o CSV não alcança: negócios, atividades e o vínculo entre registros. Também é ela que atualiza o que já existe.

Passo 1 — gerar a chave

Em Integrações → API, dê um nome à chave e gere. Ela começa com fc_ e aparece uma única vez — o sistema guarda apenas um resumo criptográfico, então não há como recuperá-la depois. Copie na hora e guarde no cofre de senhas do cliente. Se perder, revogue e gere outra.

Permissão

Somente Owners e Admins geram chaves. Se aparecer erro de permissão, confira o papel do usuário na aba Equipe.

Passo 2 — montar a chamada

Todas as chamadas seguem o mesmo formato. Troque {SUPABASE_URL} pelo endereço do ambiente do cliente — o mesmo que aparece na tela de Integrações.

# Criar um contato
curl -X POST "{SUPABASE_URL}/functions/v1/public-api/contacts" \
  -H "Authorization: Bearer fc_sua_chave_aqui" \
  -H "Content-Type: application/json" \
  -d '{
    "first_name": "Marina",
    "last_name": "Álvares",
    "email": "marina@acme.com.br",
    "phone": "11987654321",
    "title": "Diretora Comercial",
    "status": "customer"
  }'

A resposta traz o registro criado, já com o id — guarde-o, porque é ele que amarra os próximos registros:

{ "data": { "id": "8f3c…", "first_name": "Marina", "org_id": "…", … } }

O ponto que trava a carga de negócios

O stage_id aponta para um estágio do funil, e os estágios não são acessíveis pela API — ela só atende contatos, empresas, negócios e atividades. Ou seja: o funil precisa estar configurado nas Configurações antes, e os identificadores dos estágios precisam ser obtidos no banco ou com o time técnico.

Negócio criado sem stage_id entra na base, mas não aparece em nenhuma coluna do funil. Configure o pipeline primeiro.

Vincular um contato a uma empresa

É o passo que fecha o que o CSV deixou pela metade. Com os dois ids em mãos:

curl -X PUT "{SUPABASE_URL}/functions/v1/public-api/contacts/ID_DO_CONTATO" \
  -H "Authorization: Bearer fc_sua_chave_aqui" \
  -H "Content-Type: application/json" \
  -d '{ "company_id": "ID_DA_EMPRESA" }'

Carga em lote

A API grava um registro por chamada. Para uma planilha inteira, um laço resolve — com uma pausa curta entre as chamadas para não sobrecarregar o ambiente:

# negocios.csv — título,valor,data (sem linha de cabeçalho)
while IFS=, read -r titulo valor data; do
  curl -s -X POST "{SUPABASE_URL}/functions/v1/public-api/deals" \
    -H "Authorization: Bearer $CHAVE" \
    -H "Content-Type: application/json" \
    -d "{\"title\":\"$titulo\",\"value\":$valor,\"close_date\":\"$data\",\"stage_id\":\"$ESTAGIO\"}"
  sleep 0.2
done < negocios.csv

Rode primeiro com duas ou três linhas e confira o resultado na tela antes de soltar o arquivo inteiro.

04

Webhook de entrada

Endereço fixo que recebe registros vindos de fora — formulário do site, landing page, automação. Diferente da API, não usa chave por requisição, e é justamente aí que mora o problema.

Não entregar ao cliente por enquanto

O endereço não tem autenticação: ele identifica a organização por um parâmetro na própria URL e grava com privilégio total. Quem tiver o endereço consegue escrever na base — e trocando o identificador, na base de outro cliente.

Correção pendente com o time técnico (segredo compartilhado ou assinatura no corpo da requisição). Até lá, use a API pública para integrações.

Registrada a pendência, o formato é este:

POST {SUPABASE_URL}/functions/v1/inbound-webhook?org_id=ID_DA_ORGANIZACAO

{
  "entity": "contact",     // contact · company · deal · activity (no singular)
  "action": "create",      // create ou update — sem isso, assume create
  "data": {
    "first_name": "Marina",
    "email": "marina@acme.com.br",
    "phone": "11987654321"
  }
}

Os campos dentro de data são os mesmos da API pública, listados na seção anterior. Para atualizar, use "action": "update" e inclua o id do registro dentro de data.

05

Roteiro do dia 1

A ordem importa: cada passo depende do anterior. Pular a configuração do funil é o erro mais caro, porque obriga a refazer a carga de negócios.

  1. 1

    Configurar o funil antes de qualquer dado

    Estágios do pipeline, razões de perda e campos customizados. É aqui que o processo comercial do cliente vira estrutura — e negócio carregado antes disso não tem onde encaixar.

  2. 2

    Importar Empresas por CSV

    Primeiro as empresas, para que os contatos tenham a que se vincular.

  3. 3

    Importar Contatos por CSV

    Lembrando que o vínculo com empresa não vem no arquivo.

  4. 4

    Gerar a chave de API

    Em Integrações. Copie no ato — ela não é exibida uma segunda vez.

  5. 5

    Carregar negócios e atividades pela API

    Com os estágios já criados e os ids de contatos e empresas em mãos. Teste com poucas linhas antes do arquivo completo.

  6. 6

    Fechar os vínculos pendentes

    Contato para empresa, em lote pela API, ou manualmente se o volume for pequeno.

  7. 7

    Conferir com o cliente

    Total de registros, funil com os negócios distribuídos nas colunas certas e uma amostra de fichas abertas na frente dele. É o aceite da carga.

06

Erros comuns

SintomaCausaSolução
Acentos aparecem trocados depois da importação Arquivo salvo fora de UTF-8 Reexportar como CSV UTF-8, apagar o que entrou e importar de novo
Colunas desalinhadas em algumas linhas Vírgula dentro de um valor Remover as vírgulas dos textos e reimportar só as linhas afetadas
A primeira coluna não é reconhecida no mapeamento Marca invisível do Excel no início do arquivo Salvar como “CSV UTF-8 (sem BOM)” ou apontar a coluna manualmente na tela
Menos registros do que a planilha tem Linhas sem o campo obrigatório são descartadas Conferir se toda linha tem Nome preenchido
Contatos entraram sem empresa Comportamento esperado — a coluna Empresa é ignorada Vincular pela API ou na ficha do contato
Negócios não aparecem no funil Criados sem stage_id Atualizar cada um com o estágio correto via PUT
API responde 401 Chave errada, revogada ou sem o prefixo Bearer Conferir o cabeçalho e, se preciso, gerar chave nova
API responde 400 Invalid entity Nome da entidade fora da lista Usar no plural: contacts, companies, deals, activities
Base duplicada Mesmo arquivo importado duas vezes Não há desfazer — excluir as duplicatas pela tela ou pela API
Regra que evita a maior parte dos retrabalhos

Antes de soltar o arquivo cheio, importe cinco linhas e abra as fichas. Dois minutos de conferência valem mais do que limpar mil registros duplicados depois.
